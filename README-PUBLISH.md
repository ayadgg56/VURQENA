# VURQENA — حزمة النشر

ارفع الملفات التالية إلى جذر الموقع `htdocs` في InfinityFree (مع إبقاء أسماء الملفات ومساراتها):

- `index.html` — نقطة دخول التطبيق.
- `vurqena-brand.css` — طبقة الهوية البصرية التي تحملها الصفحة بعد CSS الداخلي.
- `supabase-compat.js` — طبقة التوافق المطلوبة من التطبيق.
- `assets/vurqena-mark-a.png` — الرمز الرسمي المعتمد، ويستخدم أيضاً كأيقونة متصفح.
- `sitemap.xml` و`robots.txt` — ملفا الأرشفة الموجودان مسبقاً على النطاق.

يجب الحفاظ على مجلد `assets/` كما هو بجانب هذه الملفات. لا ترفع مجلد `tests/` ولا ملفات المحاكي المحلي. ملفات الخطوط الخارجية تُحمّل من Google Fonts عند توافر الاتصال، مع sans-serif بديل.

## تحقق بعد الرفع

افتح `https://phoenix1.gt.tc/` ثم افحص أدوات المطور/الشبكة للتأكد من استجابة `vurqena-brand.css` و`assets/vurqena-mark-a.png` بحالة 200. لم يتم النشر إلى InfinityFree من هذه المهمة ولم يُختبر النطاق الحي بعد التغيير؛ تحقق منه بعد رفع الحزمة.

## نطاق التغيير

التغييرات المرئية فقط: الهوية والألوان والخطوط والأسطح والعلامة النصية/الرسومية والاستجابة. معرفات الصفحات والنماذج وسلوك المصادقة والتنقل والإدارة واتصال Supabase لم تُعدّل. استخدم اختبارات Chromium المحلية مع محاكي Supabase لاختبار الواجهة، لا بيانات إنتاج.
