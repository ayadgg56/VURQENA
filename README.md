# بيئة اختبار PHOENIX المحلية

تقدّم هذه الأدوات معاينة محلية واختبارات متصفح عبر Chromium/Playwright، مع محاكي Supabase بذاكرة مؤقتة داخل العملية. **لا تتصل هذه البيئة بـSupabase الإنتاجي ولا تكتب إليه**؛ يخضع استبدال عنوان ومفتاح Supabase لفحص صريح في `local_test_server.py`، ويرفض المحاكي أي URL غير محلي.

## المتطلبات المتاحة في بيئة Manus الحالية

- Python 3.12
- Chromium (`/usr/bin/chromium`)
- Python Playwright

لا توجد في نسخة المشروع الحالية ملفات `package.json` أو `supabase/config.toml` أو مجلد migrations كامل، كما أن Docker وSupabase CLI غير متاحين في البيئة المفحوصة؛ لذلك لم يُنشأ Supabase محلي حقيقي (PostgreSQL/Auth/Storage).

## تشغيل الاختبارات

من مجلد المشروع:

```bash
python3 tests/run_local_tests.py
```

يشغّل الأمر خادم HTTP على منفذ محلي عشوائي، ويفتح الصفحة عبر Chromium، ثم يختبر شاشة الدخول، والتبديل إلى التسجيل، ومسار تأكيد البريد وإعادة الإرسال، وعمليتي القراءة والكتابة في محوّل التوافق، وعزل الاتصال عن Supabase الإنتاجي، والفيض الأفقي في عرض الهاتف.

## تشغيل المعاينة يدوياً

```bash
python3 tests/local_test_server.py --host 127.0.0.1 --port 4173
```

ثم افتح:

```text
http://127.0.0.1:4173/__test__/index.html
```

أوقف الخادم بـ`Ctrl+C`. استخدم صفحة `/__test__/index.html` للاختبار فقط. المسار الجذر `/index (9).html` هو المصدر الأصلي ويرتبط بإعداد المشروع الحقيقي؛ لا تستخدمه للاختبارات التي قد تنفذ عمليات كتابة.

## ما الذي تثبته الاختبارات وما لا تثبته

الاختبارات تؤكد عرض الواجهة محلياً وتتحقق من بعض تدفقات Auth/البيانات عبر API وهمي متوافق مع الحد المستخدم من محوّل `supabase-compat.js`. بيانات المحاكي مؤقتة وتُمحى عند نهاية العملية. هذا ليس بديلاً عن تشغيل Supabase فعلي، ولا يثبت صحة RLS أو SQL/PLpgSQL أو تسليم البريد أو الرفع/التوقيع للوسائط أو Realtime على الخادم.

لتحقق كامل من Supabase يلزم توفير migrations الأساسية المفقودة و`supabase/config.toml`، ثم إعداد Supabase CLI مع Docker أو قاعدة staging معتمدة وحساب اختبار. اختبارات staging يجب أن تبدأ بقراءات وعمليات منخفضة المخاطر، وأن تستخدم حسابات/بيانات اختبار حصراً؛ ولا تُشغّل الترحيل المحلي واسع النطاق تلقائياً على المشروع الإنتاجي.
